# Moonlit Dungeon

A tiny browser game built for the repo so you can play immediately.

## How to play

1. Open `index.html` in a browser, or run a small local server:
   - `python -m http.server 8000`
   - then open `http://localhost:8000`
2. Use `WASD` or arrow keys to move.
3. Press `Space` to fire a magical bolt.
4. Survive the waves, collect gold, and keep the hero alive.
5. Press `R` after losing to restart.

## Goal

Defend yourself against slimes and shadows in the dungeon, gather gold, and level up.

## Files

- `index.html` – page structure
- `style.css` – visuals and layout
- `game.js` – gameplay logic and rendering

## Notes

This is intentionally lightweight and dependency-free so it runs anywhere without installing packages.

Enjoy the run.
